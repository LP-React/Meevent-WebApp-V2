# 🎉 Meevent WebApp

Meevent es una plataforma web diseñada para centralizar y promover eventos locales en el país.  
Los usuarios podrán descubrir actividades, explorar categorías y asistir a eventos fácilmente.

## 🚀 Tecnologías utilizadas

- Next.js 16
- React 19
- TypeScript
- TailwindCSS
- Vercel (deploy)

## 📦 Instalación

Clona el repositorio:

```bash
git clone https://github.com/LP-React/Meevent-WebApp-V2.git
```

Instala dependencias:

```sh
pnpm i
```

## ▶️ Ejecutar el proyecto

```sh
pnpm dev
```

## 🌱 Flujo de trabajo (GitHub Flow)

1. Crear una rama desde main

    ```bash
    git checkout -b feature/nombre-de-la-funcionalidad
    ```

2. Hacer commits siguiendo las [convenciones](#convenciones-de-commits).

    ```bash
    <tipo>: <descripción breve>
    ```
    
3. Subir la rama al repositorio remoto.

    ```bash
    git push origin -u feature/nombre-de-la-funcionalidad
    ```

4. Crear un Pull Request en Github.

5. Solicitar revisión para futuro merge.

## 📌 Convenciones de Commits

Para mantener un historial claro y consistente, todas las contribuciones deben seguir la convención.

### 🟩 Tipos de Commit

| Tipo          | Descripción                                                               |
|---------------|---------------------------------------------------------------------------|
| **feat**      | Nueva funcionalidad                                                       |
| **fix**       | Corrección de errores                                                     |
| **docs**      | Cambios en documentación                                                  |
| **style**     | Cambios de estilo o formato sin afectar la lógica                         |
| **refactor**  | Refactorización del código sin cambiar comportamiento                     |
| **perf**      | Mejoras de rendimiento                                                    |
| **test**      | Creación o actualización de pruebas                                       |
| **chore**     | Tareas menores (configs, scripts, mantenimiento)                          |
| **build**     | Cambios en configuración del build o dependencias                         |
| **ci**        | Cambios en GitHub Actions u otros pipelines                               |
