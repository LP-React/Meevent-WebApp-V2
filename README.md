## 🎉 Meevent WebApp

Meevent es una plataforma web diseñada para centralizar y promover eventos locales en el país.  
Los usuarios podrán descubrir actividades, explorar categorías y asistir a eventos fácilmente.

## 🚀 Tecnologías utilizadas

- Next.js 16
- React 19
- TypeScript
- TailwindCSS
- Vercel (deploy)

## 📦 Instalación

Clona el repositorio:

```bash
git clone https://github.com/LP-React/Meevent-WebApp-V2.git
```

Instala dependencias:

```sh
pnpm i
```

## ▶️ Ejecutar el proyecto

```sh
pnpm dev
```

## 🌱 Flujo de trabajo (GitHub Flow)

1. Crear una rama desde main

    ```bash
    git checkout -b feature/nombre-de-la-funcionalidad
    ```

2. Hacer commits siguiendo las [convenciones](#-convenciones-de-ramas-y-commits).

    ```bash
    <tipo>: <descripción breve>
    ```
    
3. Subir la rama al repositorio remoto.

    ```bash
    git push origin -u feature/nombre-de-la-funcionalidad
    ```

4. Crear un Pull Request en Github.

5. Solicitar revisión para futuro merge.

## 📌 Convenciones de ramas y commits

### 🧩 Tipos de ramas

| Tipo de rama | Formato                                | Uso recomendado                                         |
| ------------ | -------------------------------------- | ------------------------------------------------------- |
| **feature**  | `feature/<nombre-de-la-funcionalidad>` | Nuevas funcionalidades o módulos                        |
| **fix**      | `fix/<descripcion-del-bug>`            | Corrección de errores                                   |
| **hotfix**   | `hotfix/<descripcion>`                 | Arreglos críticos en producción                         |
| **refactor** | `refactor/<modulo-o-componente>`       | Reescritura o mejora interna sin cambiar comportamiento |
| **chore**    | `chore/<tarea>`                        | Mantenimiento, configuración, scripts                   |
| **docs**     | `docs/<tema>`                          | Cambios únicamente en la documentación                  |

### 🟩 Tipos de Commit

| Tipo         | Descripción                                       |
| ------------ | ------------------------------------------------- |
| **feat**     | Nueva funcionalidad                               |
| **fix**      | Corrección de errores                             |
| **docs**     | Cambios en documentación                          |
| **style**    | Formato o estilo sin modificar la lógica          |
| **refactor** | Refactorización sin cambiar comportamiento        |
| **perf**     | Mejoras de rendimiento                            |
| **test**     | Creación o modificación de tests                  |
| **chore**    | Tareas menores (scripts, configs, mantenimiento)  |
| **build**    | Cambios en dependencias o configuración del build |
| **ci**       | Cambios en pipelines o CI/CD                      |
